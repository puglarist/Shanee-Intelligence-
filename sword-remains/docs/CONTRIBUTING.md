# How to Contribute — The Sword Remains

Thank you for being part of Shanee Nation's research commons. Whether you're a grower, botanist, soil scientist, or simply someone who loves Appalachian plants, your contributions matter.

## CONTRIBUTION TYPES

### Research Submissions (No Coding Required)
- Ginseng cultivation notes or observations
- Yellow root / goldenseal propagation techniques
- Virginia snakeroot growing experience
- Soil science discoveries
- Agriforestry system designs
- Traditional / ancestral knowledge
- Regional growing condition reports
- Seed/rootstock availability

**How:** Visit `/research.html`, click "Submit Research," and fill the form.

### Code / Design Contributions
- Bug fixes or improvements to the website
- New visualizations or interactive elements
- Database improvements
- Design enhancements
- Documentation additions

**How:**
1. Fork the repository
2. Create a feature branch: `feature/your-feature-name`
3. Make changes
4. Commit with clear messages
5. Push and create pull request

### Documentation
- Writing cultivation guides
- Creating species profiles
- Documenting agriforestry systems
- Recording video tutorials
- Creating root depth diagrams
- Writing historical notes

**How:** Submit through research form or create PR with documentation.

## RESEARCH SUBMISSION GUIDELINES

### What Makes Good Research

✅ **Good submissions include:**
- What you actually observed or grew
- Your location (region, USDA zone if known)
- Timeline (how long it took, seasonal notes)
- Soil conditions (type, pH, moisture)
- Success rate (did it work? how well?)
- Challenges you faced
- Resources you used (sources, books, people)
- Photos (if possible)

❌ **Avoid:**
- Pure speculation without experience
- Plagiarized content (always cite sources)
- Extraction-focused advice (wildcrafting without propagation planning)
- Extraction-focused content (commercial harvesting without restoration)
- Extraction-based information (unsustainable yields)

### Submission Form Fields

1. **Title** - Short, descriptive title
   - Example: "Ginseng seed stratification in zone 7 clay soil"

2. **Category** - Choose one:
   - Ginseng
   - Goldenseal / Yellow Root
   - Virginia Snakeroot
   - Other Native Species
   - Agriforestry System
   - Soil Science
   - Traditional Knowledge
   - Growing Conditions / Regional Notes

3. **Description** - Your research or observation
   - What did you do?
   - What happened?
   - What did you learn?

4. **Location** - Where are you?
   - City, State, USDA Zone if known
   - Helps others apply your knowledge to their region

5. **Experience Level** - Choose one:
   - Beginner (first-time grower)
   - Intermediate (growing for 1-3 years)
   - Experienced (growing for 3+ years)
   - Professional / Researcher

6. **Sources** - What did you learn from?
   - Books, websites, mentors, personal experience
   - Include links if possible

7. **Contact** - Your name & email
   - Optional: how others can reach you
   - Optional: affiliate your work with community

## CODE CONTRIBUTION GUIDELINES

### Setting Up Locally

```bash
git clone https://github.com/puglarist/Shanee-Intelligence-.git
cd Shanee-Intelligence-/sword-remains
git checkout feature/shanee-sword-remains
```

### Branch Naming
- `feature/` for new features or content
- `fix/` for bug fixes
- `docs/` for documentation updates

### Commit Messages
Clear, descriptive commits help everyone understand changes:

```
feature: Add ginseng species database page

- Create ginseng.html with root depth visualization
- Add cultivation timeline interactive chart
- Document companion planting recommendations
```

### Pull Request Template

```markdown
## What Does This Do?
Brief description of changes

## Why?
Why is this change needed?

## How?
How does it work?

## Testing
How can someone verify this works?

## Related Research
Any botanical research this is based on?
```

## CODE STYLE GUIDELINES

### HTML
- Use semantic HTML5 tags
- Include alt text for images
- Keep class names descriptive (`pillar-desc`, not `p2`)

### CSS
- Use CSS variables for colors (never hardcode `#c8960c`)
- Use `clamp()` for responsive font sizes
- Keep media query breakpoint at 520px
- Maintain consistent spacing (2.5rem for major sections)

### JavaScript
- Keep it simple and vanilla (no frameworks unless necessary)
- Comment non-obvious logic
- Use descriptive variable names
- Test on mobile (< 520px)

## COMMUNITY GOVERNANCE

### How Contributions Are Reviewed

**Research Submissions:**
- Community votes on quality and accuracy
- Curators help organize and link related research
- If there's disagreement, discussion is encouraged
- All submissions stay visible (even disputed ones) with context

**Code Contributions:**
- At least one community member should review
- Does it fit the design system?
- Does it work on mobile?
- Is it sleek (minimal, purposeful)?
- Is it accessible?

### Becoming a Curator

After consistent, high-quality contributions, you may be invited to become a curator. Curators help:
- Organize research by topic
- Flag low-quality or extraction-focused submissions
- Connect related contributions
- Mentor new researchers
- Maintain community standards
